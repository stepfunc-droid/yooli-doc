# 有利网资产端与担保体系风险收缩时间线

> 更新日期：2026-10-16  
> 本文把已经核验到的资产端、担保公司、保理公司和有利网平台本身的重要节点放到同一条时间线上。目的不是预设“协同转移资产”等结论，而是回答一个更基础的问题：**有利网在 2020 年中公开出现兑付危机之前，其资产端和担保/代偿体系是否已经出现连续的收缩、减资、清算、司法拍卖或司法异常。**
>
> **证据边界：**时间接近不等于因果关系。下列事件分别来自监管公告、上市公司公告、报纸公告、法院裁判和平台/媒体公开回应；在没有资金流水、内部会议材料或监管处置文件前，不能据此断言这些动作是统一安排。

## 一、2018—2019：底层违约已经通过担保代偿向平台外转移

公开裁判文书显示，2018 年形成的普惠快信消费贷中，借款人发生逾期后，有利网运营主体会向融资担保公司发出《代偿通知书》，由担保公司向弘合柏基履行代偿，然后取得对借款人的追偿权。

例如：

- 程斌案（2022）皖0881民初798号：2018-09-27 起逾期，国银盛达于 **2019-06-17** 向弘合柏基代偿；
- 黄盼盼案（2023）桂1081民初3928号：2018-09-15 起逾期，国银盛达于 **2019-07-29** 向弘合柏基代偿 18,547.27 元；
- 陈昌和案（2020）琼96民终2868号：弘合柏基于 **2018-11-13** 要求诚信祥承担代偿责任，诚信祥同日向弘合柏基四川分公司汇款。

这些案例说明，平台对外显示的“出借人是否逾期”和底层借款人是否已经违约不是同一件事：**底层违约可以先被担保公司吸收，出借人侧仍维持正常回款。**

来源：

- 国银盛达诉程斌（2022）皖0881民初798号：  
  https://zh.wikisource.org/zh-hans/安徽省桐城市人民法院（2022）皖0881民初798号民事判决书
- 国银盛达诉黄盼盼（2023）桂1081民初3928号：  
  https://zh.wikisource.org/wiki/广西壮族自治区靖西市人民法院（2023）桂1081民初3928号民事判决书
- 诚信祥诉陈昌和（2020）琼96民终2868号：  
  https://zh.wikisource.org/wiki/陈昌和、深圳市诚信祥融资担保有限公司追偿权纠纷民事二审民事判决书

这与项目中已经整理的 2019 年“逾期为 0、累计代偿持续增长”现象能够互相解释：当时相当一部分底层风险可能先沉淀在资产端和担保体系，而没有立刻表现为出借人端逾期。

### 同期另一个可量化样本：赫美渠道仍挂着约 9300 万元存量

上市公司赫美集团年报持续披露，其控股的赫美小贷、赫美智科曾与有利网签署 **5 亿元合作规模**的资产/保证合作协议。到 2018 年末，有利网渠道“放款余额”仍为 **93,209,736.10 元**；2019 年末仍为 **92,631,610.53 元**。

来源：

- 赫美集团 2018 年年度报告：  
  https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=5334678&stockid=002356
- 赫美集团 2019 年年度报告：  
  https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=6329959&stockid=002356
- 赫美集团关于代偿责任合同的关注函回复：  
  https://static.cninfo.com.cn/finalpage/2019-09-27/1206952595.PDF

这说明有利网资产端不只依赖普惠快信、利信等几家机构；至少还有一批由上市公司类金融子公司提供客户、收费并承担连带保证的存量资产。

深圳市地方金融监督管理局正式批准 **深圳市国银盛达融资担保有限公司**减资：

- 减资后：**3 亿元**；
- 营业地址：深圳市福田区金田路4036号荣超大厦08层01单元。

来源：

- 深圳市地方金融监督管理局：  
  https://jr.sz.gov.cn/sjrb/xxgk/tzgg/content/post_6926024.html

国银盛达并不是与有利网无关的普通担保公司。多份判决确认，它为**普惠快信推荐至有利网的消费贷**提供连带保证，并在代偿后取得追偿权。

因此，这次减资发生在有利网关键担保节点上，时间上值得记录。但目前没有证据证明减资本身是为了逃避有利网相关代偿责任。

### 2. 淮安中院同日维持多起诚信祥追偿案“移送公安”处理

同一天，江苏省淮安市中级人民法院集中处理多起诚信祥追偿权再审案件，包括：

- （2020）苏08民再115号：朱婷婷；
- （2020）苏08民再116号：赵猛；

- 另有（2020）苏08民再87号：钱南京。

这些案件的共同处理结果是：

> 原生效民事判决被撤销 → 诚信祥起诉被驳回 → **全案移送公安机关侦查**。

再审法院使用的表述是：**“诚信祥公司可能涉嫌犯罪”**。

来源：

- https://www.tingsonglaw.com/document?doctypeno=2&fornext=ae173e8abd8879f8a9bbab567957d2b9&p=177
- https://www.tingsonglaw.com/document?doctypeno=2&fornext=e1c450b6fd52bf00871f3e5cb78faa89&p=176

### 为什么这一天值得单独标记

2020-04-24 同时出现：

- 有利网直属商业保理公司启动清算；
- 有利网消费贷核心担保方的一批历史追偿案被法院以“可能涉嫌犯罪”为由移送公安。

目前没有证据证明二者存在联系，但放在整个风险时间线上看，这是一个明显的**资产端/担保端收缩与司法异常节点**。

## 十二、把这些节点放在一起，目前最合理的解释是什么

目前已经能确认一个比“2020 年疫情突然让所有贷款变坏”更完整的过程：

```text
2018—2019
大量借款已经发生逾期
        ↓
诚信祥 / 国银盛达 / 赫美等外部体系承担保证或代偿
出借人侧风险被暂时吸收
        ↓
2020-02 国银盛达大幅减资
2020-04 普惠快信减资
2020-04 弘合柏基商业保理清算
2020-04 诚信祥一批追偿案被再审并移送公安
2020-05 赫美智科被司法拍卖并脱离原控股集团
        ↓
2020-06 有利网停止新增放款
        ↓
2020-07 出借人端逾期、债转困难集中暴露
        ↓
2020-12 赫美小贷股权进入司法拍卖
2021-03 国银盛达出现正式监管风险提示
```

这个时间序列支持一种值得继续验证的解释：

> **有利网此前能够维持“出借人端低逾期/零逾期”的重要基础之一，是资产合作方和融资担保公司的代偿能力；到 2020 年前后，不只是底层借款人恶化，整个资产端—担保端的承压体系也可能同步收缩，于是原来被吸收在体系外部的风险开始直接暴露到出借人端。**

赫美这一新增样本让这个假说更具体：它不是单纯“某家担保公司少赔了”，而是一个曾有 **5 亿元合作规模**、到 2020 年仍有约 **9200 万元存量余额**的合作体系，本身也在同一时期发生严重债务危机、子公司股权司法拍卖和控制权变化。

这是目前根据时间和合同结构得到的**分析假说**，不是已经证明的单一因果关系。

要把它进一步坐实，需要得到：

1. 2018—2020 按月、按担保公司的实际代偿额；
2. 诚信祥、国银盛达、赫美小贷/赫美智科各自在有利网体系中的担保余额和代偿上限；
3. 2020 年前后哪些合作机构停止/减少代偿；
4. 有利网逾期暴增的具体资产来源分布；
5. 资产端减资、清算、司法拍卖时是否存在尚未履行的担保/回购/代偿义务；
6. 有利网对合作机构未履行代偿义务时，是否实际主张过保证责任、追索多少、最终收回多少。
