# 有利网资产端债权流转线索

> 更新日期：2026-10-16  
> 本文承接《有利网资产端与关联公司结构梳理》《有利网资产端公司穿透调查》，只记录能够进一步说明**债权到底如何在有利网、资产端、担保方之间流转**的公开证据。
>
> 这部分尤其需要谨慎：管辖权裁定、当事人诉讼主张只能证明“曾经这样主张过”，不等于法院已经对债权转让的实体效力、金额、价格作出最终认定。

## 一、2018 年已经出现“弘合柏基 → 利信快捷”的债权受让诉讼痕迹

> **补充说明：**这里标题中的“弘合柏基 → 利信快捷”只是对诉讼表面关系的简写，**不表示已经确认弘合柏基是原始债权人或直接以自身名义处分出借人债权**。现有材料同样支持另一种可能：弘合柏基作为获得出借人授权的平台方协助办理债权转让，利信取得的是出借人债权或代偿后形成的追偿权。下文第五节对此作了进一步限定。

北京市海淀区人民法院 **（2018）京0108民初21610号** 管辖权异议裁定，是目前发现的一条非常重要的资产流转线索。

案件原告为 **深圳利信快捷金融服务有限公司**。被告包括韦娜、哈尔滨金盛元投资咨询有限责任公司、哈尔滨盛元小额贷款有限责任公司等。

裁定记载，被告在提出管辖权异议时明确主张：

- 案外人 **北京弘合柏基信息科技有限责任公司**并非债权人；
- 弘合柏基无权转让涉案债权；
- 涉案债权转让并未成立；
- 利信快捷并非原《借款协议》主体，因此原协议的管辖条款不应约束利信。

而利信快捷一方的主张则正相反：

- 涉案《借款协议》约定争议由弘合柏基所在地法院管辖；
- **利信快捷自称为“债权受让人”**；
- 其主张已经承继原债权人在该借款协议下的全部权利义务，包括管辖条款。

法院在该管辖权阶段认为，合同转让时原管辖协议对合同受让人有效，并以此处理管辖问题。

这份裁定至少说明：**到 2018 年，已经存在由利信快捷以“债权受让人”身份，基于包含弘合柏基作为协议方的借款合同，在海淀法院追索债务的案件。**

但是需要严格限定结论：

1. 该裁定处理的是**管辖权异议**，不是债权转让实体效力的最终判决；
2. 被告恰恰对“弘合柏基有没有权利转让债权”提出了争议；
3. 目前还没有拿到完整的债权转让合同，因此不能确认转让日期、转让价格、原始出借人、资金来源和债权余额；
4. 不能仅凭这一案就推断有利网曾经大规模把所有平台债权转给利信。

但它非常重要，因为它第一次把此前媒体层面的“有利网收购/控制利信、利信是资产端”进一步连接到了一条**实际债权流转诉讼链**。

来源：

- 北京市海淀区人民法院（2018）京0108民初21610号管辖权裁定（公开转载）  
  https://item.wusiku.top/A/fr/5d/bj/m1.htm

同一批当事人还出现了 **（2018）京0108民初21666号** 等案件，目前公开搜索能够确认利信快捷仍为原告，但尚未取得足够完整的裁判正文来确认其是否属于同一批债权转让安排。

## 二、普惠快信与有利网的关系可以追溯到 2014 年正式战略合作协议

四川相关诈骗刑事案件的判决书，完整引用了有利网运营主体与普惠快信之间的历史合作文件。

判决证据显示，**2014 年 4 月 10 日**，北京弘合柏基金融信息服务有限责任公司与深圳普惠快信金融服务有限公司签订《战略合作协议书》。协议约定的分工非常清楚：

### 普惠快信负责

- 消费金融借款客户开发；
- 信用审核；
- 日常管理；
- 受借款客户委托，向有利网提供借款信息和资料；
- 在借款过程中协助办理手续。

### 有利网负责

- 作为互联网信息服务平台开发、管理出借人；
- 为借款客户和出借人提供信息服务；
- 撮合借贷交易；
- 接收借款客户还款后向出借人进行分配。

更重要的是，协议还约定：通过有利网取得的借款，可以由有利网或其分公司的结算账户，**直接支付给与普惠快信合作、实际提供商品或服务的商户**。

后续的特约商户协议又进一步说明，普惠快信负责审核并向有利网推荐消费者，由消费者通过普惠快信和有利网向平台出借人申请借款。

因此，普惠快信与有利网的关系不是后来媒体笼统描述的“资产合作”，而是在至少 2014 年就形成了明确的：

> **线下消费场景/商户 → 普惠快信开发与审核 → 有利网出借人资金 → 商户收款 → 借款人还款 → 有利网向出借人分配**

链条。

来源：

- 《何某1、郑某1、尹某1等诈骗罪一审刑事判决书》，证据第84、85项  
  [《何某1、郑某1、尹某1等诈骗罪一审刑事判决书》（2018）川1403刑初112号](https://zh.wikisource.org/wiki/何某1、郑某1、尹某1等诈骗罪一审刑事判决书)

这份材料的价值在于，它把“消费贷资产是谁生产的”“有利网的钱如何进入消费场景”说明得非常具体。

## 三、利信、普惠快信曾经承载多大规模，公开说法存在明显冲突

2015 年末资产端团队离职事件中，各方披露过一批非常有价值但相互冲突的数据。

利信前 CEO 叶衍伟称：

- 利信 2015 年交易规模约 30 亿元；
- 2014 年交易规模不足 30 亿元；
- 过去两年累计为有利网提供接近 60 亿元信贷资产。

同期有报道又称：

- 利信 2015 年向有利网提供约 30 多亿元资产；
- 普惠快信提供约 20 多亿元；
- 两家合计约 50 多亿元；
- 一度有市场说法称两家公司占有利网资产端约 80%。

但吴逸然对此公开否认，称两家公司在有利网的实际资产占比**不到20%**。

因此，目前不能把“80%”“50亿元余额”等媒体数字直接当成事实，但至少可以确认：**利信、普惠快信都是有利网当年规模最大的资产端之一，而且双方曾经就资产占比公开出现巨大口径差异。**

## 四、现在最值得追的已经不是“谁是谁的子公司”，而是转让合同本身

目前最有价值的下一步不是再补工商图，而是围绕 **（2018）京0108民初21610号 / 21666号** 这一批案件继续追：

1. 原《借款协议》的完整主体是谁；
2. 原始资金是否来自有利网注册出借人；
3. 弘合柏基在其中究竟是平台服务方、代理人，还是实际享有可转让权利的债权主体；
4. 利信取得的是原始债权、追偿权、服务费债权，还是一揽子合同权利；
5. 债权转让发生在什么时候；
6. 转让对价是多少；
7. 同一批债权后来有没有实际执行回款；
8. 如果存在回款，这些回款最终进入哪个主体。

只要这一批案件能找到完整实体判决、起诉状附件、债权转让协议或执行记录，就可能第一次把“有利网平台资产 → 利信资产端 → 后续追偿”的链条真正钉死。

在取得这些材料之前，本文不把“有利网把出借人债权低价转给利信”等更强结论作为事实。

## 五、进一步核对后：资产端后来追偿，并不当然意味着“有利网把自己的资产转走了”

重庆法院关于有利网与通盛小贷合作的一系列案件，把早期业务里的**担保代偿—债权转让**机制解释得非常清楚。

公开判决记载，弘合柏基作为有利网平台运营方负责出借人开发和借贷撮合；通盛小贷负责开发、审批借款客户，并承担连带保证责任。合作协议进一步约定：

- 借款人违约后，通盛小贷向平台出借人履行代偿；
- **通盛小贷一旦代偿，出借人对借款人的相应债权自动无偿转让给通盛小贷**；
- 通盛小贷取得债权后，可以自己诉讼、继续转让等；
- 弘合柏基是获得出借人授权的代表，并有义务协助出具债权转让证明。

也就是说，在这种模式中：

> 出借人先获得担保方代偿 → 出借人的债权随代偿转给担保方 → 担保方后来起诉借款人追回的钱，原则上是它自己的追偿资产。

这非常重要，因为它提醒我们：**看到利信、利通、普惠快信、担保公司后来还在起诉借款人，不能直接推导成“这些钱本来应该还给有利网出借人”。**如果对应出借人当年已经获得完整代偿，债权本来就应该转给代偿方。

来源：

- 重庆市第五中级人民法院（2016）渝05民终3320号  
  https://cn.govopendata.com/caipanwenshu/2016/07/15/63a5f7de-e415-4d9f-b35c-7874c7f718fc/
- 重庆市南岸区人民法院（2016）渝0108民初10829号  
  https://cn.govopendata.com/caipanwenshu/2017/8/11/98fe16cf-2541-486f-9ae7-5f1ec7f87941/

类似机制在后期普惠快信资产上也能看到：例如程斌案中，深圳市国银盛达融资担保有限公司根据弘合柏基的《代偿通知书》支付借款本息后，法院认定担保公司依法取得相应借款债权，再向借款人追偿。

### 对（2018）京0108民初21610号的重新理解

这也使 21610 号案件出现了一个更合理、但仍待证实的解释：

- 弘合柏基本身未必是原始债权人；
- 它可能依据出借人的授权，代表出借人办理债权处置/转让；
- 利信取得的可能是出借人债权，而不是“有利网公司自己的资产”。

有利网历史产品协议也长期存在类似授权机制。例如定存宝协议明确约定，出借人可以全权委托有利网代为进行债权转让并以出借人名义签署相关转让协议。

来源：

- 有利网定存宝出借咨询与服务协议  
  https://www.yooli.com/static/laws/dcbxyStaticV3.jsp
- 有利网债权转让协议  
  https://www.yooli.com/static/laws/zqzr.jsp

因此，21610 号案件的真正关键已经不是“弘合柏基为什么不是债权人却能转让”，而是：

1. **谁是原始出借人；**
2. **他们在转让前是否已经得到代偿/兑付；**
3. **利信取得债权的法律触发条件是什么；**
4. **是担保代偿后的无偿承接，还是平台主动把尚未兑付债权出售给利信；**
5. **如果是出售，出借人是否授权、收到了多少转让对价。**

只有第 4、5 类情况出现异常，才真正可能与清退资产或出借人利益受损发生直接联系。

这也把后续调查范围进一步缩窄：**不能只找“资产端还在追债”的证据，而要找“没有完成代偿/兑付的出借人债权，后来被转给了谁、以什么价格转走”的证据。**
