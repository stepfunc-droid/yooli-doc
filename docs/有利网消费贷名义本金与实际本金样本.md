# 有利网消费贷名义本金与实际本金样本

> 更新日期：2026-10-16  
> 本文从公开裁判文书中抽取一小组能够同时看到“商品/实际借款金额、平台名义借款本金、一次性借款管理费”的有利网—普惠快信—诚信祥消费分期案例，用于验证一个具体问题：**有利网合同中的名义“借款本金”，与借款人真正获得的商品/资金价值之间到底差多少。**
>
> **重要限制：**目前样本只有 7 笔，且集中在 2015—2016 年的手机消费分期产品，不能外推为有利网全平台平均费率，更不能直接用于估算全部坏账本金。它只能证明这种结构不是孤立个案，并为后续扩大样本提供基准。

\* 刘某案中，诚信祥以 7,615 元作为其代偿主张基础；法院对其中管理费和部分利息另行进行了司法审查，并未简单全额支持。

从这 7 笔样本看：

- 一次性借款管理费相对于商品/实际金额的比例为 **20%—40%**；
- 中位数约 **30%**；
- 算术平均约 **29.3%**；
- 换句话说，这 7 笔合同的名义本金比借款人实际获得的商品价值高出约 **20%—40%**。

此外，如果直接把诚信祥最终主张/支付的代偿金额与商品价值比较，这组样本大约达到商品价值的 **1.8—2.3 倍**。但这一数字同时包含借款期限内利息、逾期利息等，不应简单理解成“资产端抽走了两倍费用”。

## 二、这些数字为什么重要

### 1. 有利网披露的“借款本金”不一定等于借款人的真实经济本金

以张某案为例：

- 手机实际融资金额：4,888 元；
- 有利网《借款协议》本金：6,110 元；
- 其中 1,222 元在放款时就作为借款管理费，由普惠快信及第三方服务方收取。

因此，从出借人一侧看到的是一笔 **6,110 元本金债权**，但借款人真正得到的商品价值只有 **4,888 元**。

如果这种产品结构具有普遍性，平台统计中的累计借款金额、存量本金、逾期本金，与借款人实际拿到的资金/商品价值就是不同口径。

### 2. 法院并不当然承认这些费用都是可追偿本金

多地法院对这一结构已经产生明显审查。

例如刘某案中，法院认为 1,155 元管理费超出了借款人申请借款金额，且原告未能证明借款人对该笔管理费的标准和金额得到充分明示、同意，因此不支持把该管理费及相应利息计入追偿范围。

北京大学金融法研究中心对 4531 份网贷居间费裁判文书的实证研究也专门引用了一笔有利网—普惠快信—诚信祥案例：商品价款 3,690 元、管理费 738 元，管理费占实际融资金额 20%，法院将其认定为需要与利息一并审查的借款成本。

这意味着：**合同名义债权余额，并不等于最终可以通过司法程序完整追回的本金。**

## 三、这可能怎样影响有利网后期资产质量

这批样本至少提示了三个值得继续验证的方向：

### 1. “坏账本金”本身可能包含相当比例的前置费用

如果一笔 4,000 元左右的真实消费，被包装成 5,000 多元的平台本金，那么借款人一旦违约，平台账面看到的坏账本金天然比真实商品/资金价值高。

这会导致：

> **合同本金 > 借款人真实获得价值 > 法院最终可能支持的可执行本金**

三者出现差异。

### 2. 资产端可能在贷款形成时已经提前取得部分收益

这些案例明确写明，借款管理费由**普惠快信及第三方服务方**收取，而且是在借款发放时一次性计入名义本金。

因此需要继续搞清楚：

- 这些费用最终在普惠快信、有利网、担保公司或其他服务方之间如何分配；
- 资产端是否在贷款刚形成时就已经获得主要服务收益；
- 后期坏账、代偿、清退损失主要留在了谁的账上。

目前公开判决通常只写“普惠快信及第三方服务方收取”，没有完整拆分比例。

### 3. 这可能解释为什么部分资产在清退时回收率极低

如果合同本金中本来就含有 20%—40% 的前置费用，再叠加：

- 借款人真实还款能力差；
- 长期逾期；
- 司法对高额服务费/管理费不完全支持；
- 催收、执行成本；

那么名义债权余额最后只能低折扣处置，并不奇怪。

这并不能证明有利网存在资产转移，但它提供了一个比“10 亿债权为什么这么垃圾”更具体的资产端解释。

## 五、下一步

这 7 笔已经足以证明“管理费计入平台名义本金”是一种反复出现的标准产品结构，但不足以代表整体。

后续最有价值的工作是继续扩大样本，优先抽取：

- 2015—2017 年普惠快信消费分期；
- 利信快捷现金贷/小额信用贷；
- 利通车贷；
- 不同资产端、不同年份、不同法院最终支持金额。

目标不是追求样本数量本身，而是回答两个与清退直接相关的问题：

1. **有利网历史“本金余额”里，大约有多少其实是前置服务费、管理费等非真实放款部分；**
2. **这些前置费用最终由哪些资产端/服务主体取得。**
