# 有利网严重失信借款人公示统计与“零逾期”疑点分析

> 整理日期：2026-10-13  
> 数据基础：有利网第 1—295 批严重失信借款人公示、OCR 结构化结果及汇总统计。  
> 原始归档与统计仓库：<https://github.com/stepfunc-droid/yooli-public-notice-archive>

> **统计说明：本文直接按照有利网官方第 1—295 批严重失信借款人公示进行汇总。由于公开名单本身已经对姓名、证件号和手机号作脱敏处理，本文不再自行判断不同批次之间的借款人身份。以下分析以“官方各批名单不存在重复计列同一笔逾期债务”为基本假设；如果平台实际存在重复公示，则累计金额需要相应调整。97.94 亿元表示这些官方公示记录中可读“逾期金额”的累计值，不代表某一个具体日期的平台实时逾期余额。**

---

## 一、295 批公示的总体规模

有利网自 2020 年 6 月开始陆续公布“严重失信借款人”名单。现有归档覆盖第 1 批至第 295 批，公示日期从 **2020-06-25** 延续到 **2024-10-29**。

在排除原始页面中同批重复引用图片产生的 75 条重复记录后，共整理出：

| 指标 | 统计结果 |
| --- | ---: |
| 公示批次 | **295 批** |
| 官方公示记录 | **621,387 条** |
| 可读逾期金额累计 | **9,794,144,241.81 元** |
| 折合 | **约 97.94 亿元** |
| 金额无法读取记录 | **2 条** |

统计结果与校验文件：

- [汇总 JSON](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/statistics/summary.json)
- [按借款年份汇总 CSV](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/statistics/yearly-summary.csv)
- [统计校验报告](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/statistics/verification.json)

这个规模至少说明，有利网后来需要处理的不是少量零散坏账，而是一个涉及数十万条小额个人借款记录、累计公示逾期金额接近百亿元的历史逾期资产池。

在“官方各批名单没有重复计列同一笔逾期债务”的假设下，**约 97.94 亿元可以作为这 295 批严重失信公示所覆盖逾期金额规模的近似总量**。但由于公示时间横跨 2020—2024 年，它仍不能直接等同于某一时点的平台逾期余额。

## 二、严重失信资产高度集中于 2016—2018 年形成的贷款

按“借款开始日期”所属年份汇总：

| 借款开始年份 | 公示记录 | 可读逾期金额 |
| --- | ---: | ---: |
| 2015 | 9,366 | **10.05 亿元** |
| 2016 | 119,827 | **22.44 亿元** |
| 2017 | 319,166 | **48.53 亿元** |
| 2018 | 110,132 | **14.44 亿元** |
| 2019 | 62,868 | **2.47 亿元** |
| 2020 | 28 | **20.78 万元** |

其中，**2016—2018 年借款对应的累计公示金额约 85.42 亿元，占全部可读公示金额约 87.2%**；仅 2017 年借款就对应约 **48.53 亿元，占约 49.6%**。

这组数据非常重要，因为它说明后来被列入严重失信公示的底层资产，绝大多数并不是 2020 年以后新产生的贷款，而是更早几年形成的历史信贷资产。

因此，2020 年以后公开暴露的大规模坏账更像是**此前多年形成的资产风险在后期集中显性化**，而不是在 2020 年短时间内突然形成了一整批新的问题贷款。

需要注意的是，“借款开始于 2017 年”并不等于“2017 年已经逾期”。贷款必须结合期限、还款方式、实际还款过程以及是否发生代偿才能判断何时真正形成逾期。

归档表格中可以看到 18 个月、24 个月等期限，也至少存在 36 个月贷款，因此不能把所有贷款统一按照“最长 24 个月”倒推。但对于 2017 年开始、期限 18 或 24 个月的贷款，到 2019 年 10 月时理论上已经进入或经过合同到期阶段；这使 2019 年公开披露的“逾期为 0”更加值得结合底层还款与代偿记录核查。

## 三、公示顺序显示平台是在逐步向更早年份的历史资产回溯

295 批名单并不是简单按照“新增坏账发生时间”排列。

从原始数据可以观察到明显的回溯特征：

- **第 1 批（2020-06-25）**，大量记录来自 2019 年借款；
- **第 102 批（2022-01-04）**，名单已经大量出现 2017 年借款；
- **第 214 批（2023-02-13）**，名单主要回溯到 2016 年末；
- **第 295 批（2024-10-29）**，仍在公示 2016 年中期借款。

对应原表：

- [第 1 批](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/tables/batch-0001.csv)
- [第 102 批](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/tables/batch-0102.csv)
- [第 214 批](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/tables/batch-0214.csv)
- [第 295 批](https://github.com/stepfunc-droid/yooli-public-notice-archive/blob/master/tables/batch-0295.csv)

这意味着不能把“某一年公示了多少金额”理解成“某一年新增了多少坏账”。例如，2022 年公示金额特别大，主要反映平台在这一阶段集中处理和公开更早年份的历史逾期资产。

按公示年份汇总，2021 年和 2022 年累计公示金额约 **87.72 亿元，占全部累计公示金额约 89.6%**。这更接近“清退过程中集中释放历史坏账名单”，而不是“2021—2022 年新增 87.72 亿元坏账”。

## 四、最值得解释的矛盾：2019 年仍披露“逾期为 0”

有利网历史运营数据页面显示，截至 **2019 年 10 月 31 日**：

- 借贷余额约 **126 亿元**；
- 累计代偿金额约 **6.03 亿元**；
- 逾期项目数、逾期金额仍显示为 **0**。

归档页面：

<https://wayback.yooli-action.online/statistic/platform/index.html>

而后来的严重失信借款人公示显示，大量最终形成长期严重逾期的贷款在 **2016—2018 年**就已经发放，其中 2017 年借款对应的累计公示逾期金额尤其突出。

这并不能直接证明 2019 年的“零逾期”数据是虚假的，但它提出了一个非常明确的时间问题：

> **这些后来被认定为“逾期超过 6 个月”的历史贷款，究竟从什么时候开始发生实际还款异常？在 2019 年 10 月之前已经有多少进入逾期、代偿、展期、催收或其他异常状态？**

尤其对于 2017 年发放、期限为 18 或 24 个月的借款，到 2019 年时很多已经进入或经过合同到期阶段。后续官方公示又显示，2017 年借款对应的严重失信金额约 **48.53 亿元**，是所有年份中最集中的一组。

因此真正需要解释的，不是机械比较“48.53 亿元”和“6.03 亿元”两个数字，而是：**这些老资产在 2018—2019 年到底处于什么状态，它们的风险当时是如何被识别、代偿、催收和披露的。**

如果相当数量的 2016—2018 年贷款在 2019 年已经出现实质违约，而出借人端仍持续显示“逾期为 0”，那么就需要进一步解释这些风险是如何被代偿、担保或其他安排吸收，以及普通出借人在当时能够看到哪些反映底层真实资产质量的数据。

这里仍需保留一个时间口径上的边界：后续严重失信公示延续到 2024 年，因此后来的累计公示金额不能直接等同于 2019 年某一时点的坏账或代偿余额。**但这并不影响“这些历史贷款在 2019 年前后究竟已经恶化到什么程度”成为需要核查的核心问题。**

## 五、一个可能的风险传导路径

现有公开材料能够支持一种值得进一步验证的风险传导模型：

> **底层借款人开始逾期 → 担保/合作机构代偿 → 出借人仍按时收到款项，因此平台对外“逾期”为 0 → 底层违约和代偿压力继续累积 → 代偿能力和债转流动性逐渐不足 → 2019 年末以后债转拥堵 → 2020 年公开逾期、代偿与坏账集中暴露。**

这条路径目前仍然只是基于公开数据形成的解释框架，而不是已经查实的事实。

它能解释“底层借款人已经出问题”与“出借人端仍显示零逾期”为什么可能同时存在，却仍然无法回答最关键的一点：

> **平台管理层究竟在什么时候已经知道底层资产质量显著恶化，而当时向出借人披露到了什么程度？**

## 六、目前最需要取得的底层数据

要真正解释 2019 年“零逾期”、6.03 亿元代偿与后来大规模严重失信公示之间的关系，需要取得至少以下数据：

1. 2016—2020 年逐月的底层借款逾期余额、逾期率及迁徙率；
2. 每笔代偿的发生日期、金额、对应借款合同及实际付款主体；
3. 被代偿贷款在平台运营数据中如何统计“逾期”；
4. 2017 年借款在 2018、2019、2020 年各时点的真实存量、正常还款、逾期、代偿和核销情况；
5. 2019 年末债权转让开始严重拥堵前，平台内部对资产质量、代偿资金和流动性的风险评估材料。

如果这些数据能够获得，就可以把目前的“时间上高度可疑”进一步推进为可验证的资产质量变化链条。

---

## 七、目前可以形成的结论

基于第 1—295 批严重失信借款人公示，目前可以比较稳妥地确认：

- 后来形成严重失信公示的资产高度集中于 **2016—2018 年形成的历史贷款**；
- 平台从 2020 年开始公示，并在随后数年逐渐向更早年份贷款回溯；
- 2021—2022 年是历史严重逾期名单集中释放的阶段，而不是这些坏账的实际形成年份；
- 截至 2019-10-31 仍然披露“逾期为 0”，与后来暴露出的庞大历史逾期资产池之间存在一个必须解释的时间问题；
- “第三方代偿使出借人端逾期保持为 0”在机制上可以解释部分现象，但 **2019 年底层真实违约规模、代偿主体和代偿能力仍然未知**。

因此，这批公示数据最重要的价值并不是简单给出一个“坏账总额”，而是把一个此前只能依靠媒体报道和平台汇总数字讨论的问题推进了一步：

> **大量最终严重违约的资产其实来自更早年份。接下来真正需要回答的是，这些老资产的风险究竟何时已经在平台内部显现，以及为什么直到接近 2019 年末，出借人看到的公开逾期指标仍然是 0。**
