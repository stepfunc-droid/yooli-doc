# 2019 年末至 2020 年风险穿透关键证据链

> 更新日期：2026-10-16  
> 本文把目前最能解释有利网为何在 2019 年末至 2020 年中迅速从“正常退出、逾期为 0”转为债转拥堵和大额逾期的证据集中到一条时间线上。重点不是预设犯罪结论，而是区分并连接三个层面：**底层借款信用风险、担保/代偿缓冲、定存宝债权转让流动性。**

---

## 一、2019-10-31：平台公开口径仍是“逾期为 0”，但累计代偿已经超过 6 亿元

有利网历史运营信息页在 **2019-10-31** 的披露为：

| 指标 | 平台公开数据 |
| --- | ---: |
| 借贷余额 | **126 亿元** |
| 当前借款人 | **1,658,632 人** |
| 借贷余额笔数 | **2,664,969 笔** |
| 利息余额 | **2,214,950,241.99 元** |
| 逾期项目数 | **0** |
| 逾期金额 | **0 元** |
| 项目逾期率 | **0%** |
| 逾期 90 天以上金额 | **0 元** |
| 累计代偿金额 | **60,275 万元（6.0275 亿元）** |
| 累计代偿笔数 | **86,441 笔** |

原始历史页面已经恢复在：

- [2019-10-31 运营数据恢复页面](https://wayback.yooli-action.online/statistic/platform/index.html)

平台在同一页面对“累计代偿金额”的定义是：因借款方违约等原因，由第三方（非借款人、非平台）代为偿还的总金额。

因此，这组数据本身已经能够证明一个此前非常关键的机制性事实：

> **“出借人端逾期为 0”不等于“底层借款从未违约”。截至 2019 年 10 月底，平台自己已经确认有 86,441 笔、累计 6.03 亿元左右的款项需要第三方代偿。**

这与后来查到的国银盛达、诚信祥等实际代偿判决能够互相印证。

## 二、2019-11-18：定存宝页面同时出现“平台不承诺转让时效”和“过往 1 个工作日到账”

这是目前最值得保留的一组原始产品页面证据。

`yooli-action` 已经恢复有利网 **2019-11-18** 正常运营期的定存宝列表和五种期限产品详情。选择这个时间点很重要：它不是爆雷后的清退页，而是风险全面暴露前的正常出借页面。

恢复入口：

- [定存宝列表页](https://wayback.yooli-action.online/dingcunbao/)
- [1 个月定存宝详情页](https://wayback.yooli-action.online/dingcunbao/detail/101.html)

### 页面明确揭示：服务期并不是底层债权到期日

以 1 个月产品为例，页面已经明确提示：

- 服务期结束后，如果底层借款已经到期，则由借款人还款；
- 如果仍持有未到期借款，平台按授权发起债权转让；
- 债转完成时间取决于债权转让市场；
- **平台不承诺转让时效**；
- 如果无法立即转让，持有底层债权的时间可能最长达到 **36 个月**。

这意味着用户购买“1 个月定存宝”，法律和资产结构上并不意味着底层借款也是 1 个月。

### 但同一个页面又强化了接近“定期到期”的实际体验

同一个 1 个月产品详情页同时写着：

> **“过往定存宝服务期结束后，1 个工作日内到账。”**

页面 Meta Description 还把定存宝概括为“自动出借、定时自动转让、每月获息、到期收回本金”。

这两个层面的信息必须同时保留，不能只取其一。

一方面，平台在产品页面确实披露了债转失败和长期持债风险；另一方面，**正常运营期长期形成的实际用户体验和页面表达又在强化“服务期结束≈很快拿回现金”的认知。**

所以后来大量出借人把“服务期到期却无法退出”理解为突然发生的兑付异常，并不难理解。

这不是对合同法律效力的判断，而是解释用户风险认知和产品真实运行方式之间的差异。

## 三、定存宝实际上提供了第二层风险缓冲：不是只有担保代偿

结合历史协议，风险爆发前至少存在两种不同的缓冲机制。

### 第一层：信用风险缓冲

```text
底层借款人逾期
        ↓
合作机构 / 担保公司代偿、回购或提供其他本息保障
        ↓
出借人仍收到本息
        ↓
平台公开“出借人逾期”指标仍可能为 0
```

### 第二层：流动性缓冲

```text
定存宝服务期结束
        ↓
底层借款尚未到期
        ↓
平台发起债权转让
        ↓
其他用户受让旧债权
        ↓
原出借人快速拿到现金退出
```

只要这两层缓冲同时有效，普通用户看到的体验就可以长期维持为：

> **到期很快退出 + 几乎看不到逾期。**

但这种表象并不能单独证明底层资产一直正常。

## 五、2019 年末至 2020 年初：债转流动性先开始失灵

2020 年 7 月媒体采访中，有利网客服确认：

- 定存宝到期用户按照服务期结束日期排队进行债权转让；
- 到 2020 年 7 月下旬，平台仍在处理部分 **2020-01-01 服务期已经结束**的 3 个月定存宝用户；
- 平台解释债转变慢的原因包括出借用户减少以及疫情期间借款人还款能力下降。

报道：

- 证券时报：https://news.stcn.com/sd/202007/t20200725_2166328.html
- 南方+：https://static.nfnews.com/content/202007/25/c3813683.html

这说明到 2020 年 7 月时，至少有部分用户的债转排队已经持续半年以上。

一些出借人后来称问题从 2019 年 12 月初开始明显出现。这部分目前只能作为出借人陈述，尚不能据此确定统一的“爆雷日”；但它与平台自己承认的 2020 年 1 月到期用户长期无法债转相互吻合。

## 六、最关键的数量变化：累计代偿从 6.03 亿元快速增加到 48.91 亿元

2019-10-31 平台披露：

> 累计代偿 **6.0275 亿元**。

到 2020 年 7 月公开页面和媒体引用的有利网数据已经变为：

| 指标 | 2020 年 7 月公开数据 |
| --- | ---: |
| 借贷余额 | **114.18 亿元** |
| 当前出借人 | **16.04 万人** |
| 累计代偿金额 | **48.91 亿元** |
| 逾期项目 | **269,879 个** |
| 逾期金额 | **26.78 亿元** |
| 项目逾期率 | **13.60%** |

也就是说，从 2019 年 10 月底到 2020 年 7 月，平台公开的累计代偿金额增加了约：

> **48.91 - 6.0275 = 42.8825 亿元。**

这可能是目前最有解释力的一组公开数字。

它说明：在不到一年的时间里，第三方代偿体系吸收的累计风险暴增了约 **42.9 亿元**；而到了 2020 年 6—7 月，代偿已经无法再把全部风险隔离在出借人端之外，平台同时出现约 **26.78 亿元**公开逾期。

因此，更精确的表述不是“2020 年突然出现几十亿元坏账”，而是：

> **在风险直接显示为出借人逾期之前，担保/代偿体系已经先吸收了规模极大的违约压力；随后连这层缓冲也不足以维持原来的低逾期表象。**

需要注意：累计代偿是历史累计值，不等于同一时间点实际现金损失，也不能仅凭该数字判断代偿资金来源、后续追偿结果或是否存在资金挪用。

## 七、2020 年 6 月：从“退出困难”进一步发展成“底层回款明显恶化”

媒体引用互金协会/平台数据称，截至 2020 年 6 月末：

- 当前借款人数：**1,379,331 人**；
- 比 5 月末仅减少 **5,556 人**；
- 此前几个月通常每月减少约 **7—8 万人**；
- 逾期金额：**26.78 亿元**；
- 单月比 5 月末增加约 **10.5 亿元**；
- 项目逾期率：**13.60%**；
- 金额逾期率：**20.22%**。

2020-06-30，有利网停止新增放款。

到这个阶段，问题已经显然不能只解释为“定存宝没人接债”。

**债权转让缺少买方是流动性问题；借款人减少速度骤降、逾期金额大幅增加，则反映底层资产本身的回收也在明显恶化。**

## 八、与资产端/担保端时间线叠加后，2020 年风险传导过程开始变得完整

把此前已经核验的资产端事件放进同一条线上：

| 时间 | 事件 |
| --- | --- |
| 2019-10-31 | 平台仍披露逾期 0，但累计代偿已 6.03 亿元 |
| 2019-11-18 | 定存宝正常运营页明确依赖债转退出；同时宣传历史上服务期结束后 1 个工作日到账 |
| 2019-12 | 部分出借人开始反映退出变慢；平台公开页面仍维持正常经营和扩张信号 |
| 2020-02 | 国银盛达获批注册资本 7 亿元减至 3 亿元 |
| 2020-04-03 | 普惠快信注册资本 1 亿元减至 3000 万元 |
| 2020-04-24 | 有利网直属深圳弘合柏基商业保理启动清算 |
| 2020-04-24 | 诚信祥多起历史追偿案被再审撤销民事判决并以“可能涉嫌犯罪”移送公安 |
| 2020-05 | 赫美智科 51% 股权因母集团债务问题被司法拍卖，成交价 200 万元 |
| 2020-05—06 | 平台公开逾期快速增加，借款回收速度明显下降 |
| 2020-06-30 | 有利网停止新增放款 |
| 2020-07 | 累计代偿约 48.91 亿元、逾期约 26.78 亿元，债转长期排队公开化 |
| 2020-12 | 赫美小贷 51% 股权进入司法拍卖 |
| 2021-03 | 国银盛达出现正式监管风险提示 |

这里仍然不能把所有事件写成一个已经证实的统一因果链。

但是，时间结构已经非常清楚：

> **2019 年末债转退出流动性首先承压；2020 年初至年中，底层信用风险和担保/资产合作体系又连续出现压力；到 5—7 月，两种风险开始互相强化并直接穿透至出借人。**

## 九、目前最接近完整经过的解释模型

```text
2018—2019
一部分底层借款已经违约
        ↓
担保 / 代偿 / 回购吸收信用风险
        ↓
出借人端仍可表现为低逾期甚至逾期 0

同时

定存宝服务期 < 部分底层借款剩余期限
        ↓
服务期结束靠其他用户受让旧债权完成现金退出
        ↓
正常年份形成“服务期结束后很快到账”的稳定用户体验

2019 年行业持续压降
        ↓
新增出借和债权受让需求下降
        ↓
2019 年末—2020 年初债转开始排队

2020 年
底层借款回收进一步恶化
        +
担保 / 资产合作网络承压
        ↓
代偿需求暴增
        ↓
累计代偿从约 6.03 亿元升至 48.91 亿元
        ↓
原有信用风险缓冲不能再完全覆盖底层违约

与此同时
债转旧债越来越难卖给下一位出借人
        ↓
流动性缓冲也失效

最终
大面积到期无法退出 + 出借人端逾期显性化
        ↓
折价转让 / 整账户转让 / 商城 / 穿透底标 / AMC / 属地化债权等清退方案
```

这个模型目前能够同时解释：

1. 为什么 2019 年还能披露“逾期 0”；
2. 为什么后来公示中却存在大量更早已经形成的底层问题资产；
3. 为什么用户最先感觉到的是“到期退不出来”，而不是马上看到所有底标逾期；
4. 为什么 2020 年 5—7 月逾期数据会突然跳升；
5. 为什么风险暴露后平台会越来越强调“债权仍然属于出借人”，并最终转向穿透底标和 AMC 处置。

## 十、下一步最值得查的不是再找外围公司，而是补出 2019-12 至 2020-06 的月度资金桥

现在最缺的是下面四条月度序列：

1. **借款人实际回款额**；
2. **担保/合作机构实际代偿额**；
3. **新进入出借资金及债转成交额**；
4. **新增放款额。**

只要能把这四条线按月拼出来，就能回答最核心的问题：

> **风险爆发前每个月支付给退出出借人的现金，究竟有多少来自底层正常还款，有多少来自担保代偿，又有多少来自其他出借人受让旧债权。**

目前网络上可以找到一些出借人自行统计的“新增资金、新增放款、债转金额”数据，但其计算口径和原始来源还没有完成独立核验，且部分数字与平台公开累计交易额存在口径差异。因此在核验前，本文暂不把这些民间统计写成事实。

这一步一旦补上，2019 年末到 2020 年中的风险传导过程就会从“高度可信的机制解释”进一步变成可以逐月量化的事件还原。
