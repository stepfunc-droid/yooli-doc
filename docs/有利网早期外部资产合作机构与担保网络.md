# 有利网早期外部资产合作机构与担保网络

> 更新日期：2026-10-16  
> 本文继续补足有利网资产端调查中此前容易被忽略的一层：**除利信、普惠快信、利通等较熟悉的资产端外，有利网早期还通过多家小贷、消费金融科技和担保机构获得借款资产，并把“资产开发—保证代偿—追偿”嵌入合作协议。**
>
> 本文优先使用上市公司公告、重大资产重组法律意见书和生效裁判文书，因为这些材料往往会披露普通工商页面看不到的合作额度、担保人、费用结构和存量余额。

## 一、通盛小贷：2014 年已经存在完整的“资产开发 + 双层担保 + 自动债权转让”模式

重庆多份法院判决完整披露了有利网与 **重庆市两江新区通盛小额贷款股份有限公司** 的合作模式。

### 1. 2014-04-25 签订《众筹互联网金融项目合作协议》

协议分工非常明确：

- **弘合柏基 / 有利网**：开发、管理出借人，提供信息服务并撮合借贷；
- **通盛小贷**：开发借款客户、审批、回收和日常管理；
- 通盛小贷对借款客户在《借款协议》项下的义务承担**连带保证责任**；
- 双方还设置共同监管账户，用于归集借款人还款、平台综合服务费及资产端费用。

借款人逾期且通盛未及时垫付时，有利网还可以从合作保证金中扣除应付出借人的本息以及相关费用。

来源：

- 重庆市第五中级人民法院（2016）渝05民终3320号  
  https://cn.govopendata.com/caipanwenshu/2016/07/15/63a5f7de-e415-4d9f-b35c-7874c7f718fc/

### 2. 代偿后，出借人债权自动无偿转给通盛

合作协议明确约定：

> 通盛履行代偿后，出借人在对应代偿范围内对借款人的债权自动无偿转让给通盛；通盛可以继续诉讼、转让债权；有利网作为出借人的授权代表协助出具债权转让证明。

这与后来普惠快信—诚信祥/国银盛达的消费贷模式高度一致，说明**“担保方先保本息，代偿后取得坏账追偿权”是有利网早期就已经成熟使用的业务结构。**

### 3. 某些项目还设置“第一担保人 + 通盛第二顺位兜底”

何旭案中：

- 借款人由 **重庆吉乾企业管理有限公司**提供咨询和贷后；
- 吉乾先承担连带保证责任；
- 吉乾未足额履约时，有利网再书面通知通盛小贷承担连带保证责任；
- 借款人还向通盛提供第三方反担保。

因此结构实际上可以达到：

```text
借款人
  ↓
资产服务公司/第一保证人（吉乾）
  ↓ 未履约
通盛小贷/第二保证人
  ↓ 代偿
出借人债权转给通盛
  ↓
通盛向借款人和反担保人追偿
```

### 4. 裁判还显示平台会直接从名义本金中扣收手续费

（2016）渝0108民初1162号中：

- 合同本金：500,000 元；
- 有利网放款时直接扣除手续费：6,250 元；
- 借款人实际到账：493,750 元。

另一起 100 万元借款案件中，弘合柏基扣收 5,000 元手续费后实际放款 995,000 元。

来源：

- 重庆市南岸区人民法院（2016）渝0108民初1162号  
  https://cn.govopendata.com/caipanwenshu/2016/10/30/f7da5f30-0de5-4943-ba59-10e21149d0fc/
- 重庆市南岸区人民法院（2016）渝0108民初10829号  
  https://cn.govopendata.com/caipanwenshu/2017/8/11/98fe16cf-2541-486f-9ae7-5f1ec7f87941/

这些企业经营贷的费用比例明显低于后来部分消费分期中 20%—40% 的一次性管理费，因此不同资产类型的收费结构不能混为一谈。

## 二、和创未来 / 优分期：上市公司重组文件披露了有利网 3 亿元授信合作

**北京和创未来网络科技有限公司**运营“优分期”，历史上从大学生消费分期发展到现金分期、小额个人金融服务。

2016 年华塑控股拟收购和创未来 51% 股权。由于交易属于上市公司重大资产重组，法律意见书详细披露了和创未来当时与各资金平台的合作合同，这使有利网的一条历史资产渠道第一次能够量化。

### 1. 有利网与和创未来、安家世行签署互联网金融项目合作协议

重组法律意见书列明：

- 合同：**北京弘合柏基金融信息服务有限责任公司、北京和创未来网络科技有限公司、北京安家世行融资担保有限公司《众筹互联网金融项目合作协议》及补充协议**；
- 资产来源：和创未来的平台客户；
- 资金来源：北京弘合柏基金融信息服务有限责任公司的平台客户，即有利网出借人；
- 担保责任人：**和创未来、北京安家世行融资担保有限公司、李辉、房平**；
- 授信额度：**3 亿元**；
- 截至 2016-03-31，和创未来客户在该渠道尚需支付本金、利息 **11,480,733.80 元**。

来源：

- 北京国枫律师事务所《关于华塑控股股份有限公司支付现金购买资产的法律意见书》  
  https://static.cninfo.com.cn/finalpage/2016-05-23/1202334259.PDF

同一份文件还披露，和创未来同时把资产接给人人聚财、搜易贷等平台，说明**优分期和后来的利通类似，本质上也是一个能够连接多个资金方的资产生产平台。**

### 2. 和创未来本身也是保证人，创始人还提供个人保证

有利网渠道不是“只由外部担保公司保证”。披露文件显示，和创未来自身、安家世行以及李辉、房平共同承担相关保证责任。

这说明有利网早期一些资产合作并不是简单的“资产端推荐、担保公司兜底”，而可能形成**资产端公司 + 专业担保公司 + 创始人个人保证**的多层增信。

### 3. 北京安家世行当时是正式持牌融资担保机构

北京市金融监管公开资料显示：

- 北京安家世行融资担保有限公司机构编码 **京A000055**；
- 2016 年北京市融资性担保公司综合评级中评级为 **A-bj**；
- 2022 年北京地方金融监管局仍公告延续其融资担保业务经营许可证，许可长期有效。

来源：

- 北京市融资担保机构信息表  
  https://jrj.beijing.gov.cn/tztg/201805/t20180515_727486.html
- 2016 年综合评级  
  https://jrj.beijing.gov.cn/ztzl/xzxkcfsgs/xzxkjg/201911/t20191129_749678.html
- 2022 年许可证延续公告  
  https://jrj.beijing.gov.cn/ztzl/xzzfgs/qtxzzfjg/202201/t20220120_2597125.html

因此，和创未来/优分期这条线的增信机构并不是无资质壳公司。

### 4. 一个值得记录的细节：2016 年和创未来计划退出“担保式借款合同”

重组法律意见书特别写道：根据和创未来出具的说明，在既有借款合同约定的担保责任履行完毕后，将终止上述承担担保责任的借款合同，不再与这些借出方签署新的担保式借款合同。

这反映出 2016 年监管环境变化后，资产端开始主动调整“自己给 P2P 借款提供担保”的模式。

## 三、赫美小贷 / 赫美智科：另一个有 5 亿元合作规模、且能持续看到余额的资产渠道

上市公司赫美集团的信息披露把另一条有利网历史资产渠道揭示得非常具体。

### 1. 2014-12-31 签订合作协议，合作规模 5 亿元

赫美集团向深交所回复时披露：

- 主债权人/放款渠道：**北京弘合柏基金融信息服务有限责任公司（有利网）**；
- 代偿主体：**赫美小贷、深圳赫美智慧科技有限公司（赫美智科）**；
- 债务人：自然人、法人；
- 合作规模：**500,000,000 元**；
- 协议签署日期：**2014-12-31**；
- 保证期限：合作协议项下借款发放之日起至借款到期后两年。

担保结构为：

1. 赫美智科与赫美小贷就借款客户的全部义务承担连带保证责任；
2. 赫美小贷还对赫美智科业务进行指导管理，并对其义务承担连带保证；
3. 赫美智科不履行时，出借人可以直接要求赫美小贷承担保证责任。

来源：

- 赫美集团《关于对深圳证券交易所关注函的回复更正公告》  
  https://static.cninfo.com.cn/finalpage/2019-09-27/1206952595.PDF

### 2. 这条资产渠道有非常明确的收费模型

上市公司披露的合同条款显示：

- 赫美智科一次性收取 **2% 手续费**；
- 另收居间费，按“综合费用每月 2.3%扣除年化综合资金成本后的余额”计算；
- 有利网借款协议另约定赫美小贷可向借款人收取咨询手续费、服务费、催收费等。

这再次说明：有利网出借人看到的利息只是整个借款成本的一部分，资产端还可能通过一次性手续费和居间费取得收益。

### 4. 更关键的是：赫美集团自己在 2019—2020 年已经发生严重流动性危机

赫美集团的类金融板块后来迅速失去价值和控制权：

- **赫美智科 51% 股权**因上市公司债务纠纷被司法拍卖，成交价仅 **200 万元**；2020-05-09 完成工商变更、2020-05-31 完成交割，此后不再纳入赫美集团合并范围；
- 赫美集团 2020 年年报披露，赫美智科处置时净资产约 **-3.97 亿元**；
- **赫美小贷 51% 股权**也于 2020-12-04 被司法拍卖，竞买价同样只有 **200 万元**，虽然之后拍卖执行程序又出现撤销/争议；
- 赫美集团披露赫美小贷为其类金融板块核心企业，负责客户开发、贷款资料审核、贷款发放管理和回收，并为各资金端承担代偿责任。

来源：

- 赫美智科股权处置及 2020 年报  
  https://epaper.cs.com.cn/zgzqb/images/2021-04/30/B283/zqB28330.pdf

  https://finance.sina.com.cn/roll/2021-01-05/doc-iiznezxt0585862.shtml

因此，到有利网 2020 年中风险公开爆发时，这个曾经为有利网提供 5 亿元合作额度并承担连带保证的资产/担保体系，本身已经处于严重财务困境。

这不能证明“赫美崩溃导致有利网爆雷”，但它是又一个能够直接支持下述判断的实例：

> **有利网早期的低逾期表现依赖多层外部资产端和担保方；到 2019—2020 年，部分合作机构自身也开始失去承压和代偿能力。**

## 四、把三条线放在一起：有利网早期并不是“借款人直接对接平台”这么简单

现在至少能明确还原三种典型资产合作结构：

| 资产端/合作方 | 主要资产 | 增信结构 | 已知合作规模/余额 |
| --- | --- | --- | ---: |
| 通盛小贷 + 吉乾等 | 企业/经营性借款 | 第一保证人 + 通盛二级保证 + 反担保 | 个案可达 50万—108万元；总体额度暂未查到 |
| 和创未来 / 优分期 | 学生消费分期、小额个人金融 | 和创未来 + 安家世行 + 李辉/房平个人保证 | 有利网授信额度 3亿元；2016-03余额约1148万元 |
| 赫美小贷 / 赫美智科 | 自然人/法人小额借款 | 赫美智科 + 赫美小贷连带保证 | 合作规模5亿元；2018—2021存量长期约0.92亿元 |

再加上已经单独调查的：

- 利信快捷；
- 普惠快信；
- 利通车贷；
- 诚信祥、国银盛达；
- 联合利信融资租赁；

有利网真实的资产和风险网络已经明显不是一个“平台 + 借款人”的二维结构，而是：

```text
出借人资金
   ↓
有利网平台
   ↓
多个资产端 / 获客与审核机构
   ↓
借款人
   ↕
担保公司 / 资产端自身保证 / 创始人个人保证 / 反担保
   ↓ 发生违约后
代偿 → 债权转移 → 追偿 / 再转让
```

这对解释 2019 年“逾期为 0”非常重要：**只要外部担保和代偿网络仍能支付，底层借款已经恶化也不一定立刻表现为出借人端逾期。**

## 五、目前最值得继续找什么

这轮新增的上市公司和重组披露说明，一条高收益调查方法已经比较明确：

> **不要只搜有利网自己披露什么，而要搜它的合作机构进入上市公司、融资、并购、法院诉讼时被迫披露了什么。**

下一步重点应当继续：

1. 全文检索“北京弘合柏基金融信息服务有限责任公司 / 北京弘合柏基信息科技有限责任公司”在上市公司公告、重大资产重组材料中的出现；
2. 找更多能够量化合作额度、存量余额、代偿规模的外部资产端；
3. 对已经发现的合作方，重点看 2019—2021 年是否减资、失信、冻结、拍卖、停牌照或失去代偿能力；
4. 最终将这些外部合作方的风险时间线与有利网自身代偿额、逾期额跳升时间对应起来。

这比继续从有利网自己的工商子公司名称猜用途，信息增量明显更高。
