## 一、2012—2015：平台成立、融资与快速扩张

有利网运营主体为 **北京弘合柏基金融信息服务有限责任公司**。公司成立于 2012 年，有利网于 2013 年上线。

公开报道显示，有利网在 2013—2015 年间先后获得软银中国、晨兴资本、高瓴资本等机构投资，并在 P2P 行业高速增长阶段迅速扩大业务规模。

同期平台长期使用过“100% 本息保障”“合作机构本息担保”等宣传。2014 年的官网页面、定存宝页面以及任用接受媒体专访的报道中，都能找到类似表述。

相关原始材料已整理在 `yooli-action` 的证据 1、证据 2 系列。

这里需要区分两件事：

- 风投机构投资有利网，是股权投资事实；
- “本息保障”“合作机构担保”则是平台当时面向用户形成的产品和安全宣传。

二者不是同一种法律关系。

## 二、早期业务结构：平台、资产方和担保方分工

公开裁判文书显示，有利网早期大量业务采用“平台 + 外部资产机构 + 担保机构”的模式。

以重庆通盛小贷相关案件为例，法院披露的合作协议显示：

- 弘合柏基 / 有利网负责开发和管理出借人、提供信息服务并撮合借贷；
- 通盛小贷负责开发、审批、回收和管理借款客户；
- 通盛对相关借款承担连带保证责任；
- 借款人逾期且通盛未及时垫付时，有利网可以从合作保证金中扣除出借人当期应收本息及相关费用；
- 通盛完成代偿后，出借人的相应债权按约转移给通盛，由通盛继续追偿。

- [有利网早期外部资产合作机构与担保网络](./有利网早期外部资产合作机构与担保网络.md)

除通盛外，上市公司和重大资产重组材料还披露了其他合作渠道：

- 和创未来 / 优分期与有利网存在 **3 亿元**合作授信安排；
- 赫美小贷 / 赫美智科与有利网存在 **5 亿元**合作规模；

这些资料来自合作方自身的上市公司披露、重组文件和裁判文书。

## 三、2015 年以后：有利网开始向资产端延伸

2015 年以后，多篇同期财经报道开始出现有利网“向资产端布局”“收购资产端机构”“建设信贷工厂”等表述。

第一财经 2015 年报道提到，有利网开始从过去的“纯平台”向资产端延伸，涉及“有利普惠”“有利投资”“有利资本”等业务方向。

2016 年公开采访中，有利网方面称已经完成对若干资产方的收购和整合，其中：

- 深圳利信快捷主要从事小额信贷；
- 深圳普惠快信主要从事消费分期；
- 有利网计划进一步建设消费金融“信贷工厂”。

需要注意：媒体所称“收购”并不等于所有时期的工商登记都能直接显示股权控制，因此具体控制方式仍需逐家公司区分。

### 普惠快信

公开刑事判决书引用的 2014 年《战略合作协议书》显示，普惠快信负责：

- 消费金融客户开发；
- 信用审核；
- 日常管理；
- 向有利网提交借款客户资料并协助办理借款手续。

后续大量追偿案件又出现稳定的合同结构：

> 普惠快信开发和审核借款人 → 有利网撮合平台注册出借人 → 诚信祥或国银盛达提供担保 → 借款人违约后担保方代偿并追偿。

### 利通车贷

公开裁判文书显示，北京利通汽车咨询服务有限公司及其分支机构曾负责：

- 客户获取和资料审核；
- 融资方案；
- GPS 安装和车辆抵押手续；
- 贷后管理和催收；
- 在部分有利网借款中承担担保或代偿责任。

历史招聘资料曾直接将利通称为“有利网旗下子公司”；目前没有仅凭该招聘资料认定具体股权关系。

### 利信快捷

有利网公开称完成对利信等资产方的收购；利信前 CEO 叶衍伟曾在媒体中称，工商大股东代红光是“有利网方面的代持人”。这一说法属于当事人公开陈述，并非司法认定。

裁判材料还能确认：

- 利信自身曾直接形成和持有借款债权；
- 利信参与设立深圳市联合利信融资租赁有限公司；
- 联合利信后续长期处理历史融资租赁债权。

## 四、2017—2019：合规、监管接入和备案相关公开信息

2017 年以后，有利网确实进入过多个行业自律或监管数据系统：

- 2017 年，中国互联网金融协会信息披露系统首批试点单位之一；
- 2017 年底，产品登记功能首批接入机构之一；
- 2019 年，有利网公开称成为国家互联网应急中心实时数据报送系统首批接入平台之一。

这些事项与“P2P 备案通过”不是同一概念。

有利网历史“备案信息”页面对地方金融监管部门备案仍显示：

- 备案登记地方金融监管部门：**备案后披露**；
- 备案登记时间：**备案后披露**；
- 备案登记编号：**备案后披露**。

目前没有发现地方金融监管部门正式公布有利网已完成 P2P 备案，或正式列入监管试点机构名单的文件。

与此同时，2018—2019 年的平台官网和公开采访中持续出现“合规头部平台”“备案前景”“监管系统接入”“安全、真实、可信赖”等表述。

2019 年 9 月，有利网官网文章在介绍“成熟一家、纳入一家”的监管试点政策后写道，这对“诸如有利网这类始终坚持合规发展的网贷平台”属于利好。

## 六、2019-10-31：平台官网同时披露“逾期 0”和累计代偿 6.03 亿元

有利网历史运营数据页面显示，截至 **2019-10-31**：

| 指标 | 平台公开数据 |
| --- | ---: |
| 借贷余额 | 约 **126 亿元** |
| 当前借款人 | **1,658,632 人** |
| 借贷余额笔数 | **2,664,969 笔** |
| 利息余额 | 约 **22.15 亿元** |
| 逾期项目数 | **0** |
| 逾期金额 | **0 元** |
| 逾期 90 天以上金额 | **0 元** |
| 累计代偿金额 | **60,275 万元（约 6.03 亿元）** |
| 累计代偿笔数 | **86,441 笔** |

平台页面对“累计代偿金额”的定义，是由于借款方违约等原因，由非借款人、非平台的第三方代为偿还的金额总和。

因此，这两个字段需要分别理解：

- “逾期金额”是平台对外披露的逾期统计字段；
- “累计代偿金额”记录的是第三方因借款人违约等原因已经发生过的代偿。

两者是否能够同时为“逾期 0 + 已发生代偿”，取决于当时的统计定义、代偿时间以及出借人实际收款状态。

## 七、担保代偿并不总是在借款人首次违约后立即发生

公开裁判文书能够看到多笔“借款人违约时间”和“担保方正式代偿时间”之间存在较长间隔的案件。

例如：

- 程斌：2018-09-27 起逾期，国银盛达于 2019-06-17 代偿；
- 黄盼盼：2018-09-15 起逾期，国银盛达于 2019-07-29 代偿；
- 部分诚信祥案件中，借款人停止按约还款后较长时间，弘合柏基才发出代偿通知书；
- 一份诚信祥追偿判决中，法院直接写明担保方“并未及时代为偿还”。

另有通盛小贷合作协议明确约定：如果通盛没有及时垫付，弘合柏基可以先从合作保证金中扣除出借人当期应收本息和相关费用。

有利网历史定存宝协议中也出现过“代偿、债权回购、发放后备贷款”等本息保障方式。

公开材料目前不能证明诚信祥、国银盛达相关案件在正式代偿之前具体使用了哪一种资金安排。

## 八、定存宝的服务期与底层借款期限并不相同

有利网历史定存宝页面和协议显示：定存宝设置的是“服务期”，不是所有底层借款统一到期日。

服务期结束时：

- 如果对应借款已经到期，由借款人还款；
- 如果仍持有未到期债权，平台根据出借人授权发起债权转让；
- 如果债权没有立即转让成功，出借人继续持有底层债权。

2019-11-18 正常运营期的产品页面同时出现两组文字：

> **平台不承诺转让时效。**

以及：

> **过往定存宝服务期结束后，1 个工作日内到账。**

1 个月产品的说明还提示，无法及时完成转让时，相关底层债权持有时间可能最长达到 **36 个月**。

## 十一、2020 年 6—7 月：停止新增放款、债转排队和逾期数据上升

同一时期媒体引用有利网或中国互联网金融协会数据称，截至 2020 年 6 月末 / 7 月下旬：

| 指标 | 公开数据 |

| 借贷余额 | 约 **114.18 亿元** |
| 当前出借人 | 约 **16.04 万人** |

## 十二、2020-06-30 以后，定存宝仍有新的出借资金进入

2020-11-24，《21世纪经济报道》报道记者在 11 月 23 日实测有利网时发现：

- 仍有 3、6、12、24 个月定存宝；

有利网历史定存宝协议允许出借资金用于：

公开报道没有穿透披露 2020-06-30 之后每一笔新进入定存宝资金实际匹配的底层债权，因此目前无法仅凭产品仍在募集，判断这些资金究竟形成了新贷款还是用于受让存量债权。

## 十四、2021 年：正式退出 P2P 撮合业务

2021-04-01，有利网发布《关于公司的近期情况更新》，宣布退出网络借贷信息中介撮合业务。

该公告由平台自述以下数据：

- 累计“本息全回”出借人 **15 万人**；
- 上述人群获得收益约 **47 亿元**；

## 十五、2021—2022：第三方资管和属地化债权认领

有利网现存标准合同包含出借人对平台的债权处置授权。在借款人和担保方均未履行义务时，合同文本允许弘合柏基代表出借人：

- 诉讼和催收；
- 委托第三方专业机构；
- 将债权转让给资产管理公司等第三方；
- 代签债权转让和委托协议。

目前公开的标准文本不能证明所有历史出借人、所有时期都适用完全相同版本，需要结合具体账户合同核验。

2021-12-28，有利网发布“最终债权兑付方案”，推出属地化债权认领。公开转述所载结构包括：

- 出借人原账户债权转让给第三方资管公司；
- 再按照待收本金名义金额 1:1 置换指定地区债权；
- 认领后由出借人继续持有、等待回款、自行或委托催收；
- 部分债权还可继续折价转让给第三方资管。

2022 年 1 月的公告进一步称：

- 提供现金转让通道的第三方资管与有利网签署过合作协议；
- 该资管实际出资收购过有利网债权；
- 有利网称被收购债权质量和回款不及预期，双方不再续约。

截至目前，公开材料仍未披露或未能确认：

- 第三方资管公司全称；
- 股东和实际控制人；
- 总收购本金；
- 平均折扣；
- 实际回收额；
- 交易回款最终分配明细。

# 十八、基于上述材料的分析与判断

> **以下内容不再是单纯的事实罗列，而是本项目在现有公开证据基础上形成的分析。它可以随着新证据出现而修正。**

## 1. 有利网的业务不是一个简单的“虚构标的”体系

现有裁判文书、合作协议、上市公司披露、担保追偿案件和审计资料能够互相印证大量真实借款、真实资产合作、真实担保代偿和真实司法追偿。

因此，目前没有证据支持把有利网整体描述成一个主要依靠虚构借款人或虚假标的运行的平台。

这不代表其所有业务都已经被证明没有问题，也不排除具体资产、具体合同或具体资金流存在需要继续调查的事项。

## 2. 有利网后来已经形成了自己的资产端能力

从管理层公开战略、媒体所述收购整合、普惠快信和利通的实际业务角色、利信及联合利信的业务链条来看，有利网在早期依赖外部资产机构之后，后来确实向借款人开发、审核、贷后、担保和催收等环节纵向延伸。

因此，更准确的描述是：

> **有利网后期形成了“自建/收购/控制型资产端 + 外部合作资产端”并存的混合资产来源。**

但“自建资产端”不等于“自融”。自融需要进一步证明出借人资金最终用于平台自身、股东、实际控制人或关联企业的融资需求；目前公开证据还不能完成这一层证明，2018 年专项审计在其范围内也未发现自融。

## 3. “逾期 0”不能被理解成底层借款人没有违约

2019-10-31 平台同时披露逾期金额 0 和累计代偿约 6.03 亿元，而平台自己对累计代偿的定义已经包含“借款方违约等原因”。

结合后续担保追偿案件，可以判断：

> **出借人是否按时收到钱，与底层借款人是否按时还钱，是两个不同层面的指标。**

担保、合作保证金、回购、后备贷款等机制都可能使底层信用问题暂时不直接表现为出借人逾期。

## 4. 定存宝的快速退出长期依赖债权转让市场

定存宝服务期与底层借款期限并不一致。服务期结束后，如果底层债权尚未到期，需要其他用户受让旧债权才能让原出借人现金退出。

因此，即使底层借款没有立即违约，只要愿意接债的新出借人减少，定存宝也可能出现长期排队。

这使 2019 年行业“降规模、降人数、促退出”的监管环境与有利网后来的债转拥堵之间存在明确的机制联系。

## 5. 目前最能解释 2019—2020 变化的是“两层缓冲同时减弱”

现有材料可以把风险机制分成两层：

```text
信用风险缓冲：
借款人违约 → 担保 / 代偿 / 合作保证金 / 回购等 → 出借人仍可能正常收款

流动性缓冲：
定存宝服务期结束 → 其他用户受让旧债 → 原出借人现金退出
```

2019 年行业持续压降首先减少了新出借人和债权买方；2019 年末开始出现长期债转排队。

进入 2020 年后，平台公开数据又显示借款回收和逾期明显恶化；同时部分资产端和担保合作机构出现减资、财务危机、司法拍卖、清算或监管风险。

因此，目前最能同时解释公开数据和时间顺序的模型是：

> **债转流动性先减弱，随后底层信用风险与代偿压力进一步上升；当流动性和信用两层缓冲都无法继续维持原有运行状态时，风险集中暴露到出借人端。**

## 6. 平台关于“行业恶化 + 疫情冲击”的解释具有现实证据基础

2019 年整个 P2P 行业确实处于持续压降和退出过程；2020 年有利网公开数据也确实出现借款人数下降速度异常放缓、逾期快速增加、累计代偿大幅上升。

部分历史资产端和担保合作方同期也存在经营和偿付压力。

因此，现有证据支持：**行业持续恶化和 2020 年疫情冲击，是有利网风险暴露的重要背景和原因之一。**

但现有公开材料还不能精确量化：行业压降、疫情、底层原有资产质量、担保方承压各自贡献了多少损失。

## 7. 仍然需要继续核查风险披露和清退透明度

即使接受行业和疫情是重要原因，仍有几类问题没有因此消失：

- 平台内部何时已经确认债转流动性难以恢复；
- 2018—2019 年实际底层违约和代偿压力与出借人可见信息之间有多大差距；
- 借款人首次违约到担保正式代偿之间，出借人的按期回款由什么资金来源完成；
- 2020 年下半年新进入定存宝的资金实际承接了哪些债权；
- 清退阶段第三方资管是谁、以什么价格受让债权、累计追回多少、回款如何分配。

这些问题目前应继续保持“待核查”状态，而不是提前给出违法或无违法的结论。

## 8. 本项目目前的总体判断

综合现有公开材料，本项目目前更倾向于把有利网事件描述为：

> **一家真实经营多年、拥有大规模真实借款业务，并在后期形成自身资产端能力的大型 P2P，在行业持续压降过程中首先出现债权转让流动性恶化；2020 年又叠加借款人还款恶化及部分资产端、担保体系承压，原有的代偿和债转机制无法继续维持此前的回款与退出状态，最终进入长期清退。**

同时，以下事项目前仍不能作为已查实事实：

- 系统性自融；
- 违法资金池；
- 有组织地转移资产；
- 用新出借人资金直接兑付旧出借人；
- 第三方资管与股东、高管或资产端存在未披露关联；
- 有意把优质资产优先兑付给特定人群、把劣质资产集中留给最后出借人；
- 故意虚假披露或诈骗。

这些问题是否成立，需要比现有公开网页、媒体报道和零散裁判文书更高等级的资金、账户、监管或司法证据。
