# 有利网事件分析

本仓库用于整理和分析[有利网（yooli.com）](https://www.yooli.com/) P2P 事件的公开资料、历史公告、审计报告、裁判文书、媒体报道与出借人留存材料，重点还原平台从快速扩张、资产端纵向整合、行业压降、流动性恶化、风险穿透到清退和债权处置的完整过程。

这里的基本原则是：**把事实、平台自述、公开宣传、媒体/当事人陈述、分析性推断严格分层。** 对于自融、资金池、虚假披露、关联交易、资产转移、选择性兑付等问题，在没有司法调查、完整流水、底标台账或穿透式审计结论前，不作为已经查实的事实表述。

## 当前总体判断

经过对官网历史快照、公开运营数据、审计报告、上市公司公告、重大资产重组文件和大量裁判文书的交叉核对，目前对有利网可以形成一个比“单纯 P2P 暴雷”更完整的描述：

> **有利网并不像一家主要依赖虚构借款或空壳资产运行的平台。公开材料能够验证大量真实借款人、真实资产合作机构、真实担保/代偿、银行存管和后续司法追偿。**
>
> **但有利网也并非始终只是一个完全独立于资产生产方的纯信息中介。2015 年以后，平台明确向车贷、小额信用贷和消费金融等资产端纵向延伸，通过收购、整合、自建和深度控制型合作形成了自己的资产生产、审核、贷后和风险处置能力，同时仍保留通盛小贷、优分期、赫美等外部资产合作渠道。**
>
> **2018—2019 年以后，行业持续压降首先削弱了定存宝依赖的债权转让流动性；底层违约则长期由担保、代偿、合作保证金、债权回购等机制吸收。2019 年末至 2020 年中，债转买方减少、疫情冲击借款人还款、资产端和担保端自身承压，多层缓冲先后失效，风险才集中穿透到出借人端。**

因此，本仓库现在的调查重点已经从“资产是不是真的”逐步收缩到几个更具体的问题：**风险到底何时已经明显恶化、管理层何时知道、向出借人披露是否充分，爆雷前退出资金究竟来自底层还款/代偿/债转的哪一部分，以及清退后的坏账和债权最终如何被处置。**

## 当前最重要的证据边界

### 已经可以较明确确认

- 有利网存在真实的借款、资产合作、担保代偿、司法追偿和银行存管体系；
- 有利网早期主要依赖外部资产机构，2015 年以后明确向资产端纵向延伸，并形成自己的信贷资产生产能力；
- 后期业务形态更接近“自建/控制型资产端 + 外部合作资产端”的混合模式；
- “出借人侧逾期为 0”并不等于底层借款从未违约，2019-10-31 同期已经存在约 6.03 亿元累计代偿；
- 定存宝服务期与底层借款期限并不相同，历史快速退出高度依赖债权转让流动性；
- 2019 年末至 2020 年中，债转流动性、底层信用风险和部分资产端/担保端的承压同时恶化；
- 2021—2022 年第三方资管公司确实参与过现金收购和债权置换，但其身份和交易细节仍不透明。

### 目前不能直接确认

- 不能因为有利网自建资产端就直接认定存在“自融”；
- 不能仅凭公司关系、减资、清算或司法拍卖认定存在资产转移；
- 不能把后续严重失信公示的累计金额倒推成 2019 年已经存在的同额坏账；
- 不能把担保公司后来追偿取得的回款当然认定为应当再次返还给已经获得代偿的原出借人；
- 不能在未取得 AMC 合同、付款流水和交易台账前认定清退债权被关联方低价转走。
