# 有利网事件分析

本仓库用于整理和分析[有利网（yooli.com）](https://www.yooli.com/) P2P 事件的公开资料、历史公告、审计报告、媒体报道与出借人留存材料，重点还原平台从快速扩张、合规整改、风险暴露到清退的完整过程。

这里的文档以“事实、平台自述、公开宣传、媒体报道、分析性疑点”分层整理。对于自融、资金池、虚假披露、关联交易等问题，在没有司法调查、完整流水或穿透式审计结论前，均不作为已经查实的事实表述。

## 我们现在最想搞清楚什么

随着严重失信公示、合同期限和后续清退数据逐步整理出来，现在已经有几条很明确的调查主线。

最突出的一条是 **2019 年“逾期为 0”到底代表什么**。截至 2019-10-31，平台公开逾期仍为 0、累计代偿约 6.03 亿元，但后来进入严重失信公示的贷款中，按公示人次累计约 **62.6570 亿元**对应的原始合同在这个时间点前已经最终到期。这个数字不能直接等同于“2019 年已经有 62.66 亿元坏账”，但它把问题收得很窄：这些贷款当时究竟是正常还清、展期、重组、被代偿，还是已经发生了没有体现在出借人侧“逾期”指标里的底层违约？

另一个问题是风险为什么会在很短时间里突然显性化。2019 年 10 月还是“逾期 0”，到 2020 年 7 月公开逾期已经约 26.78 亿元、累计代偿接近 48.91 亿元，2021 年平台又称坏账接近 70 亿元、底标逾期率接近 90%。这里到底有多少是 2020 年新发生的恶化，又有多少其实是更早已经存在、只是此前被代偿、债转、展期等机制吸收了，需要继续往下查。

同时还要继续搞清楚几件事：当时的合规、安全、监管接入等宣传和普通出借人真正能看到的风险之间有没有明显落差；清退阶段到底还剩多少独立、真实、可回收的债权；现有专项审计和合规报告到底覆盖到了哪里，又有哪些地方从来没有被真正穿透。

这些问题目前都还是**调查问题，不是已经定性的结论**。详细的已知事实、证据边界和下一步要找的材料，集中放在：[当前核心问题与调查清单](docs/当前核心问题与调查清单.md)。

本仓库的目的不是预设结论，而是尽可能把公开可核验的信息串联起来，回答几个核心问题：风险何时形成、平台是否及时充分披露、不同阶段出借人的退出条件为何明显不同，以及平台、资产端、担保方之间的真实关系是否需要进一步穿透调查。
