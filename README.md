# 有利网事件分析

本仓库用于整理和分析[有利网（yooli.com）](https://www.yooli.com/) P2P 事件的公开资料、历史公告、审计报告、媒体报道与出借人留存材料，重点还原平台从快速扩张、合规整改、风险暴露到清退的完整过程。

这里的文档以“事实、平台自述、公开宣传、媒体报道、分析性疑点”分层整理。对于自融、资金池、虚假披露、关联交易等问题，在没有司法调查、完整流水或穿透式审计结论前，均不作为已经查实的事实表述。

## 说明

本仓库的目的不是预设结论，而是尽可能把公开可核验的信息串联起来，回答几个核心问题：风险何时形成、平台是否及时充分披露、不同阶段出借人的退出条件为何明显不同，以及平台、资产端、担保方之间的真实关系是否需要进一步穿透调查。

如发现材料错误、遗漏或有新的公开证据，欢迎提交 Issue 或 PR。
