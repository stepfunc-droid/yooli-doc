# 有利网事件资料整理

本仓库用于整理[有利网（yooli.com）](https://www.yooli.com/) P2P 事件相关的公开资料，并将平台官网历史快照、公告、审计与合规报告、上市公司披露、重大资产重组文件、裁判文书、媒体报道以及出借人留存材料按主题归档和交叉核对。

仓库的主要目标是**还原事件经过和保存可复核资料**，而不是预先给事件定性。

这里统一采用以下证据分层：

- **已确认事实**：能够由原始公告、官网历史页面、审计报告、监管文件、上市公司披露、裁判文书等直接支持的内容；
- **平台自述 / 公开宣传**：有利网及相关公司对外发布的说法，记录原文和发布时间，但不自动视为独立验证后的事实；
- **媒体 / 当事人陈述**：媒体采访、出借人或其他当事人的说法，需要与原始材料进一步核对；
- **分析性推断**：基于多份材料进行的时间、结构或机制分析，应与事实部分分开，并尽量放在专题文档后部；
- **尚待核查问题**：自融、资金池、关联交易、截留回款、资产转移、选择性兑付、清退债权低价处置等，在没有司法调查、完整流水、底标台账或穿透式审计结论前，不作为已经查实的事实表述。

## 阅读顺序

第一次接触有利网事件，建议先阅读：

1. [有利网事件说明](docs/有利网事件说明.md) —— 按时间和资料来源还原平台从成立、扩张、资产端建设、行业压降、风险暴露到清退的主要经过；分析与判断集中放在文末。

公开资料已经能够恢复大量合同、运营数据和外部合作关系，但以下材料仍然缺失或不完整：

- 底标级实际还款流水；
- 出借人实际回款流水；
- 担保、合作保证金和正式代偿流水；
- 债权转让逐笔台账；
- 2019-12 至 2020-06 的月度资金流与新增放款数据；
- 平台内部风险分类和管理层会议材料；
- 向监管部门报送的风险报告、检查和整改文件；
- 第三方资管公司的完整合作协议、债权清单、付款记录及最终回收数据。

这些材料如果出现，应优先用于补充和修正现有文档。
